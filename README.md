# Mobile Money API

Backend API for a Mobile Money system designed to simulate core digital payment and wallet operations.

## Features

* Money transfer between users
* Deposit
* Withdrawal
* Merchant payment
* Savings
* Transaction history
* Secure authentication and authorization
* Transaction status management
* Idempotent transaction processing
* Ledger-based transaction tracking

## Tech Stack

* Java 21
* Spring Boot 4
* PostgreSQL 17
* Docker & Docker Compose


## Core Concepts

This project focuses on implementing backend concepts commonly found in digital payment systems:

* Wallet and balance management
* Atomic financial transactions
* Transaction lifecycle and statuses
* Idempotency
* Ledger entries
* Concurrency and race-condition handling
* Data consistency
* Secure API design

## Project Goal

The goal of this project is to understand how the backend of a Mobile Money system can be designed and implemented, from wallet operations to transaction processing and accounting.
